# mobile-calculadora

App de calculadora simples desenvolvido com React Native + Expo usando componentes do React Native Paper.

## Funcionalidades

- Display para valores e resultados
- Botões numéricos e de operações
- Operações básicas: `+`, `-`, `*`, `/`
- Botão `C` para limpar

## Como executar

```bash
npm install
npm run start
```

Para abrir direto no navegador:

```bash
npm run web
```
